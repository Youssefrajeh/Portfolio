نغم — مشغّل موسيقى شخصي (PWA)

التشغيل محلياً:
  python -m http.server 8080   ثم افتح http://localhost:8080

النشر (مجاني): ارفع المجلد كما هو إلى Vercel أو Netlify أو GitHub Pages (يحتاج HTTPS ليعمل كتطبيق).
التثبيت على الهاتف: افتح الرابط في Chrome > القائمة > "إضافة إلى الشاشة الرئيسية".
